# NASCAR 26 Mod Manager

Install tracks and mods for NASCAR 26 by dragging them onto a window. It keeps them working after NASCAR 26 updates and updates itself.

## Download

**[NASCAR 26 Mod Manager 1.0.21](https://github.com/goldensloth1/NASCAR26-Mod-Manager/releases/download/v1.0.21/NASCAR26-ModManager-1.0.21.zip)** - unzip it anywhere (e.g. Documents), start `NASCAR26 Mod Manager.exe`, then drag a track or mod `.zip` onto its window.

Windows may say "Windows protected your PC" the first time because the app is new: click **More info**, then **Run anyway**.

## Offline only

Mods are for offline play only. With mods installed, NASCAR 26 closes itself the moment it starts going online (the online menu, lobbies, invites, live events, online races), and every DLL mod runs only while that lock is on. To race online, press **Play online (no mods)** in the Mod Manager: that start of the game has no mods at all, and your mods are back the next time you start the game normally.

## Free Cam controls

Turn it on and off on the keyboard (press the same key again to go back to your car):

- **F5**: free cam with the race frozen (in a replay, the replay holds where it is)
- **F6**: free cam with the race still running

On-screen UI is hidden while the free cam is on.

**Keyboard and mouse**

| | |
|---|---|
| Move forward / back | W / S, or Up / Down arrow |
| Move left / right | A / D |
| Up | E or Space |
| Down | Q, C or Left Ctrl |
| Look | Mouse, or I / K (up / down) and J / L (left / right); Left / Right arrow also turn |
| Faster / slower | Shift + plus / Shift + minus, or numpad + / - (two presses double or halve it, 1/8x to 16x) |

**Controller**

| | |
|---|---|
| Move | Left stick |
| Look | Right stick |
| Up | A (Cross on PlayStation), or click the left stick |
| Down | Click the right stick |
| Tilt the camera | Right trigger clockwise, left trigger anticlockwise; both fully pressed = level again |

Fly with **F5** when you use a controller: with F6 the controller also still drives your car.

## Updates

Nothing to do: the Mod Manager checks this page's `updates.json` every time it starts. New versions of the Mod Manager and of your installed mods install themselves, and after a NASCAR 26 update your mods are fixed by themselves as soon as the matching update is published here.

Close NASCAR 26 before installing.
