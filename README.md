# NASCAR 26 Mod Manager

Install tracks and mods for NASCAR 26 by dragging them onto a window. It keeps them working after NASCAR 26 updates and updates itself.

## Download

**[NASCAR 26 Mod Manager 1.0.19](https://github.com/goldensloth1/NASCAR26-Mod-Manager/releases/download/v1.0.19/NASCAR26-ModManager-1.0.19.zip)** - unzip it anywhere (e.g. Documents), start `NASCAR26 Mod Manager.exe`, then drag a track or mod `.zip` onto its window.

Windows may say "Windows protected your PC" the first time because the app is new: click **More info**, then **Run anyway**.

## Updates

Nothing to do: the Mod Manager checks this page's `updates.json` every time it starts. New versions of the Mod Manager and of your installed mods install themselves, and after a NASCAR 26 update your mods are fixed by themselves as soon as the matching update is published here.

Close NASCAR 26 before installing.
